# Datasets

The datasets are not included in this repository because of their size (about 194 MB).

Sources: IMD gridded rainfall (2000-2023), NASA POWER weather, India Flood Inventory, CWC water levels, Odisha GIS layers (district boundaries, river network, historical floods), WorldPop 2020, Census 2011 towns, OpenStreetMap (Overpass). Live data: Open-Meteo weather and GloFAS river discharge (Open-Meteo Flood API).
